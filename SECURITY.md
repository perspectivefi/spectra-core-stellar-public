# Security Policy

Please report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repository. Include affected components, impact, reproduction steps, and any
suggested remediation.

Do not disclose a vulnerability publicly before the maintainers have had a
reasonable opportunity to investigate and coordinate a fix. Reports will be
acknowledged and triaged as promptly as practical.

The included [Certora audit report](audit/README.md) describes the audited
revision, scope, findings, and status. An audit does not eliminate risk.
